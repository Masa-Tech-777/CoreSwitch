CoreFlow Extreme v2.7.13　Windows 11 x64


CoreFlow Extremeは、日本で開発したWindows 11（x64）用のCPU調整アプリです。コンセントにつないで作業するときと、バッテリーで動画を見るときに、それぞれ使いたいCPUの最大周波数・最小周波数の目安・ブーストモードを保存できます。設定名、横の［？］の説明、確認画面、使い方ガイドを日本語で読めます。本体を英語に切り替えるとMonitorも英語で表示します。

■ 設定できること

・最大周波数は、CPUのクロックをどこまで上げるかの上限です。CPU仕様データベースで確認できた最大周波数まで指定でき、0を入力すると上限指定を解除します。
・最小周波数は、入力したMHzをWindowsの「最小プロセッサ性能」に換算するための目安です。たとえば設定可能な下限の400MHzを入力しても、実測クロックが400MHzまで下がることや、400MHzを下回らないことは保証されません。
・ブーストモードは、負荷がかかったときに、基本周波数を超える性能をWindowsがどう求めるかを選ぶ設定です。電源接続時とバッテリー駆動時で個別に選べます。

選んだプランの複製に設定を適用し、15秒以内に［この設定を維持］を押すと、元のプランごとに設定を記録します。

■ ブーストモードの選び方

・0 無効 — Windowsにブーストを使わないよう指定します。
・1 有効（標準） — 作業に応じてブーストを許可します。どこまで周波数を上げるかはCPUとWindowsが決めます。
・2 アグレッシブ — 負荷がかかったときに、より積極的にブーストを要求します。
・3 効率的な有効化 — 必要な性能を得るときに、電力効率も考慮するモードです。
・4 効率的なアグレッシブ — CPUの制御方式に応じて、電力効率を考慮した動作または積極的なブーストを使います。
・5 アグレッシブ（保証） — CPUの保証性能レベルを基準に、必要な追加性能をWindowsが計算して要求します。
・6 効率的なアグレッシブ（保証） — CPUの保証性能レベルを超える範囲で、Windowsが可能な限り高い性能を求めます。

「効率的」は電力効率を考慮する方式を指します。「保証」はCPUが示す性能レベルの名称です。同じように動くモードもあり、番号順に速くなったり省電力になったりするわけではありません。設定横の［？］でも選択中のモードを確認できます。

HWiNFOでCPU温度やクロックをさらに詳しく見る

Martin Malík様（REALiX）作のHWiNFOは、CPUコアごとの温度、コアクロック、実効クロックを詳しく確認できる外部アプリです。対応するセンサーはPCによって異なります。

1. Monitor右上の［HWiNFOを起動］を押し、案内の［OK］で進みます。HWiNFOが見つかれば起動します。

2. 未導入なら［公式ダウンロードページ］からインストーラー版またはポータブル版を入手します。公式ダウンロード先は https://www.hwinfo.com/download/ です。導入済みで見つからない場合は［導入済みのEXEを選択…］からHWiNFO64.exeを選びます。本体の［ヘルプ］→［HWiNFOの実行ファイルを設定…］でも登録・変更できます。

3. HWiNFOのセンサー画面を開き、見たいCPUセンサーの［現在］を確認します。

HWiNFO 64の無料利用は非商用向けです。業務で使う場合は公式の利用条件を確認してください。HWiNFOは独立して測定します。Monitorの温度欄を使う場合は、下のPawnIOの手順をご覧ください。

たとえば、Monitorに「CPU Package 60℃」、HWiNFOに「Core 0 最大 76℃」と出ていても、両方とも正しく測れていることがあります。前者はCPU全体を代表するセンサーの現在値、後者は一つのコアで測定開始またはリセット後に記録した最高値です。比較するときはHWiNFOのセンサー画面で同じセンサーの「現在」を選びます。Monitorが代表値に使うのはIntelのCPU PackageまたはAMDのCore (Tctl/Tdie)を一つに特定できた場合です。「TjMaxまでの距離」は温度上限までの余裕を表します。

Monitorの温度取得は約1秒間隔です。二つのアプリが同時に読むとは限らず、短い発熱の山を片方だけが拾うことがあります。最低・最高・平均を比較するときは両方の統計を同じ頃にリセットし、同じ作業を同じ時間だけ測ります。Monitorの平均は有効な読み取り値の平均です。一時停止や読み取り失敗で欠けた値を0℃として数えません。瞬間のずれを調べるときは、先にHWiNFOのCSV記録を開始して発生時刻を控えてください。

Monitorの観測クロックはWindowsの区間推定値です。HWiNFOのCore Clockはコアの状態を読み取った時点の値で、Effective Clock（実効クロック）はコアが休止していた時間も含めた測定間隔の平均です。比較したい指標を決め、同じ負荷と時間帯で記録してください。

初めてCPU温度を表示する

Monitorの温度欄に案内が出たら［PawnIOの導入方法を見る］を押します。

CPU温度を表示するために、namazso様作のPawnIOドライバーを使用します。温度を見たいときだけ、作者の公式サイトから導入してください。周波数の設定や、MonitorのCPU使用率・観測クロックはPawnIOを入れずに使えます。

1. ［PawnIO公式サイトを開く］を押し、Download Nowから署名付きの公式版を入手します。
2. セットアップを起動し、左下のモニターに下向き矢印が付いたアイコンを押します。注意事項を確認し、［OK］を押します。
3. インストール成功のメッセージ「PawnIO was successfully installed.」が表示されたら［OK］を押し、セットアップ右上の［×］で閉じます。再起動を求められたときは、その案内に従ってください。
4. Monitorを一度閉じ、本体の［モニターを表示］で開き直します。一時停止中は［測定を再開］を押してください。

導入後も温度が表示されないときは、［温度詳細］の状態を確認してください。「権限が必要です」と表示された場合は、管理者確認を済ませたExtreme本体からMonitorを開きます。取得モジュールが見つからない場合は配布ZIPを全体ごと展開し直してください。表示できるセンサーは機種によって異なります。

動作を確認した環境と、お使いのPCで確かめる項目

Windows 11 x64のdynabook S73/FR（Core i7-10510U、PawnIO導入済み）でCPU温度の表示を確認しています。RyzenやPコア・Eコア混在機で同じセンサーや制御結果が得られるかは実機未確認です。CPU仕様データベースに一致せず上限を確認できない場合、数値を指定する上限制御は適用できません。必要な電源設定をWindowsから読めない場合も適用を中止します。性能クラスの追加設定は読み取れる項目だけを使用します。電源モード、メーカーの温度・電力制御、作業負荷によって周波数やファン音は変わります。Monitorの観測クロックにはCPUの基本周波数とWindowsの計測値が必要です。購入前の60分体験で、温度欄・設定の適用・元のプランへの復元をお使いのPCでお確かめください。
