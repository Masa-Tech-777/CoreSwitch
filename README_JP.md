CoreSwitch
README JP / 配布用説明書
============================================================

v3.0.15

■ はじめに

CoreSwitchは、Windowsで毎日繰り返す操作を4つのツールで楽にする、日本発のアプリです。
コピーした文章を探して貼り直す、作業ごとにデスクトップを分ける、PCとスマートフォンで
単語登録を使い回す、日本語と英数字をすばやく切り替える、といった操作に使えます。
4つのツールを管理する画面を「司令塔」と呼びます。使いたいものをここから起動できます。
日本語の画面と手順で使えます。英語の説明書（README_EN.txt）も同梱しています。
本体の版番号は司令塔の画面下部または［ヘルプ］→［About］で確認できます。

■ 動作環境

Windows 11 64ビット向けです。司令塔、Dictionary Core、Virtual Desktop Toolは
通常権限で動作します。ClipSelとAlt-Spaceの起動には管理者権限が必要です。

■ 同梱モジュール

・ClipSel v4.1.8 — 以前にコピーした文章や画像を呼び出せます。定型文も登録できます。
・Virtual Desktop Tool v2.0.0.4 — ショートカットで作業画面を切り替えられます。
・Dictionary Core v2.3.0 — よく使う言葉の登録内容を編集し、別の入力アプリへ移せます。
・Alt-Space v3.2.11 — Alt、Space長押し、変換・無変換キーで入力モードを切り替えられます。

■ はじめて使うとき

1. 配布ZIPをすべて展開します。CoreSwitch.exe と Modules フォルダーは
   同じ階層に置き、ファイル名とフォルダー構成を保ってください。
2. CoreSwitch.exe を開き、使いたいモジュールの［起動］を押します。
   ［常駐モジュールを起動］を押すと、常駐用の3つをまとめて起動します。
   Dictionary Coreは一覧の［起動］から開きます。
3. ClipSelとAlt-Spaceの権限確認が出たら、アプリ名を確かめて承認します。

［司令塔設定］では、Windows起動時にCoreSwitchを起動するか、
どの常駐モジュールを自動起動するかを設定できます。
ウィンドウの［×］は司令塔を格納します。終了には［司令塔を終了］を使います。

■ 最初の1分でClipSelを試す

1. CoreSwitchの一覧で［ClipSel］の［起動］を押します。メモ帳を開き、
   「りんご」と「みかん」を1回ずつ選択して、それぞれ Ctrl+C でコピーします。
2. メモ帳の貼り付けたい位置をクリックし、Ctrl+Shift+U を押します。
   ClipSelの［履歴］タブに、直近にコピーした「みかん」が表示されます。
3. 「りんご」の行をダブルクリックします。メモ帳に「りんご」が入れば成功です。
   一覧に戻るにはもう一度 Ctrl+Shift+U を押します。Escで一覧を閉じられます。

■ ClipSelで探す・並べる・貼り付ける

ClipSelが起動している間にコピーした対応データが履歴に入ります。文章の貼り直しに加え、
複数のメモを組み立てたり、決まった挨拶文を定型文から呼び出したりできます。
試験用のテキスト履歴100万件で保存・検索・スクロールを確認しました。実際の速度や
必要なディスク容量は、PCの構成と履歴の内容によって変わります。

・検索欄に語句を入れると履歴全体を検索し、完全一致、先頭一致、部分一致の順に
  最大100件を表示します。検索欄を空にすると全履歴に戻ります。
  検索していない一覧は、ホイールやスクロールバーで末尾まで続けて移動できます。
・離れた行を好きな順番で貼るには、まず1行をクリックし、2行目からは
  Ctrlを押しながらクリックします。Enterで選んだ順に改行して貼り付けます。
  例えば8行目をクリックし、Ctrlで3行目、6行目と選ぶと「8 → 3 → 6」の順です。
  Ctrlで選び直した行は最後に回ります。
・連続した行は、最初の行をクリックし、Shiftを押しながら最後の行をクリックします。
  Enterで画面の上から下の順に貼り付けます。キーボードで1件ずつ順番を指定するには、
  一覧にフォーカスを置き、矢印キーで移動してSpaceでチェックし、Enterを押します。
・何件かを個別に続けて貼るときは Ctrl+Shift+Y で一覧を開きます。
  一覧を開いている間は Ctrl+Y で連続貼り付けをオンにし、
  Ctrl+U で解除して単発貼り付けに戻せます。
  よく使う文章は［定型文］タブの［新規登録］から登録し、ダブルクリックで使えます。
・画像を貼るときは1件だけ選びます。エクスプローラーでコピーしたファイルを
  貼るには、元のファイルが同じ場所に必要です。
・履歴を消すには、対象の行を選び、選択範囲内で右クリックして削除を選びます。
  確認画面の件数を確かめてください。個別・範囲削除した項目は一覧と検索から消え、
  再起動後も貼り付け対象から外れます。元の本文や添付データは保存先に残ります。
  すべての履歴の本文・添付データを消す場合は［全履歴を消去］を使います。

■ Virtual Desktop Toolで作業画面を切り替える

仮想デスクトップは、1台のPCでウィンドウを作業ごとに分けておくWindowsの機能です。
たとえば、資料を読む画面と文章を書く画面を作っておくと、必要な画面に切り替えられます。
Alt+I で新しいデスクトップを作成、Alt+K で左へ移動、Alt+O で右へ移動、
Alt+L で現在のデスクトップを閉じます。

■ Alt-Spaceで日本語と英数字を切り替える

Alt-Spaceの起動後に Ctrl+Alt+I を押すと設定が開きます。［基本スタイル］で
Alt単押し、Space長押し、または両方を選びます。Alt単押しは、左・右・両方から
選べます。日本語配列の変換・無変換キーで切り替えたい場合は、それぞれ
［IME切り替え］を選び、［設定を適用］を押してください。任意で画面中央に
入力状態を表示できます。Google日本語入力では、テスト環境でカーソル付近の
「あ」「A」の表示も確認しました。

Google日本語入力で「_A」が出て、英数字のまま日本語に戻らないときは、Alt-Spaceで
IME切り替えに割り当てたキーを一度押してください。テスト環境では、Alt、変換、
無変換のそれぞれでひらがなに復帰しました。切り替えがうまくいかない場合は、
キーボードの［カナ／かな］キーでも復帰をお試しください。

■ Dictionary CoreでPCとスマートフォンの単語登録を使い回す

ユーザー辞書には、よく入力する名前や住所、専門用語などを短い「読み」で登録できます。
Dictionary Coreは、元の入力アプリから出力した辞書を開き、移行先で読み込める
形式に書き出します。例えば、PCのGoogle日本語入力に登録した単語を、スマートフォンの
flickへ移せます。書き出したファイルは移行先の端末に転送し、その入力アプリで取り込みます。

■ ATOK単語ファイル変換（ベータ）

Dictionary CoreでATOK、Google/Mozc、MS IME、Simeji、flickの辞書ファイルを
相互変換できます。ATOKでは、辞書ユーティリティの［単語・用例の一覧出力］から
出力した単語ファイル（テキスト）を［ATOK（ベータ）］で開いてください。
ATOKへ移すときは［ATOKへ保存（ベータ）］で出力し、ATOKの辞書ユーティリティで
［ファイルから登録・削除］を使います。出力文字コードはBOM付きUTF-16LEです。

読みと単語を変換し、品詞やコメントは保存先の形式に応じて引き継ぎます。
対応しない品詞の名詞化や、置換候補・言語タグなどが省略される場合は、
保存前に案内が表示されます。元の辞書は別に保管してください。
5形式間の入出力は試験データで確認済みです。ATOKへの実際の登録や、各IME・端末の
すべての版での取り込みは未確認です。初回は少量を別の辞書に登録してご確認ください。

■ 60分無料体験とライセンス登録

ライセンス未登録時は、累積60分間の無料体験ができます。
発行されたキーを登録すると、時間制限が解除されます。キーは申請したPCのマシンIDに
対応します。［ライセンスを削除して試用版に戻す］を実行すると登録が解除され、
消費済みの試用時間が引き継がれます。同じマシンIDなら受け取ったキーを再登録できます。
v3.0.9からは、CS1-で始まる署名付きキーを使います。
旧版のキーをお持ちの方は、マシンIDと注文番号を添えて再発行をご依頼ください。

1. ［ライセンス］→［ライセンス登録・管理］を開きます。
2. BOOTHで購入後、申請画面に従ってマシンIDとBOOTH注文番号をお知らせください。
   ［申請文＆宛先を一括コピー］または［メール申請 (メーラー起動)］が使えます。
3. 届いたキーを入力し、［認証して登録］を押します。

■ 更新通知と上書き更新

1. 新版の配布ZIPをダウンロードして、いったん別の場所にすべて展開します。
2. 使用中のCoreSwitchで［司令塔を終了］を押します。モジュールの終了を待ちます。
3. 展開したCoreSwitchフォルダーの中身を、今お使いのCoreSwitch.exeがある
   フォルダーへコピーします。Windowsに確認されたら［ファイルを置き換える］を
   選び、いつものCoreSwitch.exeを開きます。

元のフォルダーはそのまま使います。配布ZIPには個人の履歴・定型文・設定を
含めていないため、上書き更新のためにそれらを別の場所へ移す作業はありません。
起動時にGitHubの公開リリースを確認し、新版が見つかったらダウンロードページを
開くか尋ねます。手動で確認するには［ヘルプ］→［GitHubで更新を確認］を選びます。

■ 起動できないとき

モジュールは司令塔から起動してください。起動認証エラーが繰り返される場合は、
CoreSwitch.exe の名前と、同じ階層に Modules があることを確認してください。
問い合わせ時は、版番号、モジュール名、エラー文面をお知らせください。
起動診断ログは %AppData%\MasaTech\CoreSwitch\Diagnostics にあります。
ログを共有する前に内容を確認してください。ライセンスキーやクリップボード履歴の送付は不要です。

■ 保存先とアンインストール

ClipSelの履歴と定型文は Modules\Data または
%LocalAppData%\MasaTech\CoreSwitch\ClipSel\Data に保存されます。
司令塔の設定は %AppData%\MasaTech\CoreSwitch に保存されます。
取り外すときは、司令塔設定でWindows起動時の登録を解除し、［司令塔を終了］を押します。
履歴や定型文を今後も使いたい場合は、保存先の Data を別の場所に控えてから
展開先のフォルダーを削除してください。AppDataの設定やデータは別途管理できます。
